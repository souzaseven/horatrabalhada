# ⏰ Calculadora de Horas Trabalhadas

![Preview da Calculadora](https://via.placeholder.com/800x400/007ced/ffffff?text=Calculadora+de+Horas)

Ferramenta web para cálculo preciso de horas trabalhadas, incluindo turnos e intervalos, com detecção automática de horas extras.

## ✨ Funcionalidades

### 🔄 Cálculo Automático
- **Turnos múltiplos**: Calcula primeiro e segundo turno
- **Intervalos**: Contabiliza tempo entre turnos
- **Horas extras**: Detecção automática (acima de 8h)

### 🛠 Ferramentas
| Recurso | Descrição | 
|---------|-----------|
| Foco automático | Transição entre campos preenchidos |
| Detalhamento | Exibe horas por turno e intervalo |
| Limpeza rápida | Botão para resetar todos campos |
